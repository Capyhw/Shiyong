# 拾用界面约定

沿用已确认 HTML 原型，采用紧凑桌面工具布局：左侧应用中心、我的应用、仅收藏列表、底部设置；右侧工具目录。窗口使用真实系统边框，不模拟 macOS 红绿灯。

配色：正文 #25314a、次要文字 #68738a、侧栏 #f5f7fb、纸面 #ffffff、强调色 #5263d6、浅强调 #eef0ff。暗色通过语义变量替换。字体为系统无衬线字体，正文左对齐。

应用图标用 API 的 URL，图片失败回退 Lucide Blocks；搜索、收藏等操作图标用 Lucide。添加不自动收藏，移除同时取消收藏。移除使用原生 dialog 元素保留键盘焦点管理。

主菜单只搜索我的应用，收藏优先，方向键与回车可用；应用中心保留所有目录应用，平台不支持时禁用添加/打开。网页应用用“添加/移除”，未来原生应用采用“安装/卸载”。

首版视觉重点是少量独立窗口组成的说明插图，其他区域保持简洁，避免模拟操作系统桌面。支持窄屏布局、键盘焦点和减少动态效果；桌面真实窗口最小宽度为 760。
