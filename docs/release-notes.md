拾用 v0.1.3

- 重新设计应用中心、我的应用和快速打开菜单，提供更紧凑的侧栏、工具栏搜索与图标 / 列表视图。
- macOS 26 及以上使用原生 Liquid Glass，macOS 27 支持玻璃交互效果；旧版系统保留原生材质回退。
- 主界面与快速菜单统一采用官方 WebView 嵌入玻璃容器的方式，修正内容与玻璃圆角层级，保留原生阴影。
- 新增跟随系统外观，并保留已有用户的浅色 / 深色选择；窗口与内容外观同步。
- 改进快速菜单键盘选择、搜索与中文输入法处理，支持主界面搜索和设置快捷键。
- 保留应用、收藏、独立应用管理与签名更新能力。
- 提供 macOS Apple Silicon / Intel 和 Windows x64 安装包。

macOS 请将拾用拖入“应用程序”后运行。若从 0.1.1 升级后未显示窗口，请退出后重新打开一次，或下载 DMG 覆盖安装。应用内更新签名及 macOS ad-hoc 签名已启用；尚未配置 Apple Developer ID 签名、公证及 Windows 代码签名。
