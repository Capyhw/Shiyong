拾用首个公开版本。

- 应用中心合并网页工具与独立应用，支持按需添加、安装和卸载。
- 收藏列表、菜单栏 / 系统托盘、全局快捷键和独立网页窗口。
- 支持从设置页检查拾用更新，下载经过签名校验的更新包并安装重启。
- macOS 提供 Apple Silicon 和 Intel 安装包，Windows 提供 x64 安装包。
- NetSplit 目前仅支持 Apple Silicon Mac。
- macOS 应用包带完整 ad-hoc 签名，CI 验证包完整性后才发布。

macOS 请将拾用拖入“应用程序”后运行。应用内更新签名已启用；目前尚未配置 Apple Developer ID 签名、公证及 Windows 代码签名。
